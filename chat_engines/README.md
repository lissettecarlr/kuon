# Kuon 聊天引擎设计文档

聊天引擎是一个集成了多种功能的对话系统，旨在提供更智能、更有记忆力的AI助手体验。该系统整合了记忆功能和多能力处理（MCP）功能，使AI助手能够记住用户的偏好和历史交互，并能够调用外部工具执行任务。

## 核心组件

聊天引擎由三个主要组件构成：

1. **ChatEngine**：核心控制器，整合MCP和Memory Chat功能
2. **MemoryChatAssistant**：具有长短期记忆能力的对话助手
3. **OpenAIMCPClient**：多能力处理客户端，用于调用外部工具和服务

## 架构设计

### ChatEngine

ChatEngine作为核心控制器，负责协调MCP和Memory Chat之间的交互：

- 如果用户选择使用MCP，则先调用MCP客户端获取工具返回的结果
- 将MCP结果和原本用户问题作为增强输入，传入Memory Chat
- 如果用户不使用MCP，则直接使用Memory Chat处理请求

### MemoryChatAssistant

MemoryChatAssistant实现了具有记忆能力的对话助手：

- **双层记忆结构**：短期记忆存储最近对话，长期记忆存储压缩后的重要信息
- **自动记忆压缩**：定期将短期记忆压缩为长期记忆，保留重要信息
- **记忆持久化**：支持将长期记忆保存到文件系统，确保对话记忆不丢失
- **上下文管理**：自动监控并控制对话上下文长度，避免超出模型限制
- **流式响应**：支持流式返回AI回复，提升用户体验

### OpenAIMCPClient

OpenAIMCPClient实现了多能力处理客户端：

- 支持通过配置文件加载并初始化多个服务器
- 支持不同类型的MCP服务器（SSE和标准输入/输出）
- 使用Agent框架处理用户请求并调用适当的工具
- 资源管理：提供初始化和清理功能，确保资源正确释放

## 工作流程

1. 用户发送消息，可选择是否使用MCP增强
2. 如使用MCP，系统先判断是否需要调用外部工具
3. 调用工具并获取结果，或返回"无"表示不需工具辅助
4. 将原始消息和工具结果（如有）合并为增强消息
5. MemoryChatAssistant处理增强消息，生成回复
6. 回复内容被记录到短期记忆中
7. 短期记忆定期或在达到阈值时被压缩成长期记忆
